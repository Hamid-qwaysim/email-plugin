Recover abandoned carts, generate smart AI coupons, and automate store marketing. Connects to the AI Revenue Recovery Engine SaaS via a license key.

== Description ==

AI Revenue Recovery Engine connects your WooCommerce store to an AI marketing
backend that recovers lost sales, generates personalized coupons with margin
protection, and automates lifecycle email — all controlled by your subscription.

When your subscription is active, premium features run. If it expires, is
canceled, or is disabled by an administrator, the plugin immediately pauses all
premium functionality.

Features include visitor intent tracking, abandoned cart recovery, an AI coupon
engine, email autopilot, on-site personalization, exit-intent offers, product
recommendations, and a store health dashboard. (SMS is not included.)

== Privacy ==

Visitor behavior is tracked to power recovery and personalization. The plugin
supports implied or explicit consent modes and an admin-exclusion option. No
data is sent to the SaaS while the license is inactive.

== Installation ==

1. Install and activate WooCommerce.
2. Upload and activate this plugin.
3. Go to "AI Revenue" in the WordPress admin and run the Connection wizard.
4. Paste your Store ID, license key, and one-time signing secret.
